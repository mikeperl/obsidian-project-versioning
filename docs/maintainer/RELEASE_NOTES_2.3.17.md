# Project Versioning 2.3.17

Initial public release of Project Versioning.

## Highlights

- Create complete ZIP snapshots of vault folders, whole vaults, or explicitly selected external desktop project folders.
- Compare snapshots and generate human-readable reports for added, deleted, modified, moved, metadata-only, and generated/derived files.
- Maintain per-project Version History with snapshot creation status and change summaries.
- Manage retained snapshots with newest-snapshot protection, manual deletion, consecutive-duplicate removal, and optional retention policies.
- Keep managed versioning data in private default storage or a validated custom storage folder, including safe migration between storage locations.
- Export selected snapshots to an optional local export folder or copy every new snapshot automatically.
- Edit project definitions while preserving project identity and archive lineage.
- Validate project, storage, and export paths before saving, including drive-root, overlap, duplicate-source, hidden-folder, and Windows system-folder safeguards.
- Provide explicit cleanup controls for retained versioning data without deleting project source files.

## Privacy and platform

Project Versioning is desktop-only, local, and offline. It makes no network requests and contains no telemetry, analytics, accounts, ads, or cloud upload. Optional external filesystem access occurs only for paths explicitly configured by the user.

## Compatibility

Requires Obsidian 1.13.0 or later.
