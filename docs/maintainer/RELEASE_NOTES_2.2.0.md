# Project Versioning 2.2.0

This release prepares Project Versioning for public distribution through the Obsidian Community directory.

Highlights:

- complete local ZIP project snapshots;
- line-level and binary comparison;
- move/rename detection;
- human-readable Markdown and JSON reports;
- multi-project support;
- snapshot manager with protected newest snapshot;
- configurable retention policies;
- offline operation with no telemetry, accounts, or external tools;
- Community submission-oriented privacy disclosures, linting, CI, and release automation.
